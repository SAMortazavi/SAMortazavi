## 🚀 Selected Industry Work

### 🎧 Call-Center Quality Intelligence

Independently designed and delivered an end-to-end production workflow for large-scale call analysis.

The system combines:

- Automatic Speech Recognition
- Voice Activity Detection
- Acoustic Emotion Recognition
- LLM-assisted Sentiment Analysis
- Conversation Tagging
- Call Summarization
- Cross-talk Detection
- Long-silence Analysis
- Forbidden-word / Policy Checks
- Agent Apology Analysis
- Structured Analytics APIs

It currently processes **1,000+ calls per day**.

Beyond model inference, I also use the resulting data for operational and business analysis, helping identify call-quality, recording, process, and workflow issues.

### 🔐 Robust Speech Watermarking

Developed the data generation, training, and evaluation workflow for a **16-bit speech watermarking system**.

## 🎓 Research & Academic Background

### M.Sc. Electrical Engineering — Bioelectric
**Sharif University of Technology**

**GPA:** 19.02 / 20  
**Rank:** 1st / 17  
**Thesis Grade:** 20 / 20

**Thesis**

> *Eye Tracking Using EEG Signals During Simultaneous Functional Magnetic Resonance Imaging*

The project investigates EEG-based gaze decoding both outside and during simultaneous EEG-fMRI acquisition.

Work included:

- EEG and eye-tracking data analysis
- Gradient and cardiac artifact removal for simultaneous EEG-fMRI
- Temporal and frequency-domain feature engineering
- Hjorth parameters
- Alpha / Beta band-power features
- Subject-specific machine-learning pipelines
- SVM, KNN, Random Forest, and XGBoost
- Held-out test-set evaluation

Selected outside-scanner results:

- **99%** — passive viewing
- **94%** — three-class gaze direction
- **~86%** — five-class gaze direction

Preliminary in-scanner results from one participant:

- **85%** — three-class
- **100%** — passive viewing
